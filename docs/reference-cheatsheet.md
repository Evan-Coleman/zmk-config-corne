# ZMK Corne Cheat Sheet (Single Page)

## COMBOS - All on Main Layer
```
SYMBOLS (vertical top+home):        BRACKETS (horizontal):
Q+A = !    Y+H = ^                  E+R = (    U+I = )
W+S = @    U+J = &                  D+F = [    J+K = ]
E+D = #    I+K = *                  C+V = {    ,+. = }
R+F = $    ;+P = ?                  R+T = <    Y+U = >
T+G = %

OPERATORS (diagonal home+bottom):   PROGRAMMING:
D+C = ~    J+M = -                  .+/ = =>   (fat arrow)
F+V = \    K+, = _                  H+N = ->   (thin arrow)
           L+. = =                  G+H = &&   (logical AND)
           P+/ = +                  L+P = ||   (logical OR)

COMFORT:                            SPECIAL:
W+E = ESC      K+L = ENTER          F+J = Caps Word
I+O = BSPC     corners = BT Layer
```

## LAYERS
```
0 MAIN   = default        3 MOUSE = Raise+Z (auto-exit)
1 LOWER  = hold L-thumb   4 BT    = Lower+Raise together
2 RAISE  = hold R-thumb
```

## THUMBS
```
Main:   TAB | Lower | SPACE     BSP/DEL | Raise | Magic
Others: TAB | →Main | SPACE     BSP/DEL | →Main | Magic
Mouse:  →Main|→Main | LClick    RClick  | →Main | →Main
```

## HOME ROW MODS (hold = mod, tap = letter)
```
A=Shift  S=Ctrl  D=Alt  F=Gui  |  J=Gui  K=Alt  L=Ctrl  P=Shift
```

## MAGIC KEY (right thumb)
```
tap = sticky shift    double = caps word    hold = shift
after letter = repeat that letter
```

## SEMICOLON
```
tap = ;    double-tap = :
```

## SWAPPER (Lower layer, N key)
```
tap = start Cmd+Tab    keep tapping = cycle    M = reverse
any other key = confirm selection
```

## LEADER KEY (Raise layer, N key)
```
b+0/1/2/3 = BT profile    b+c = BT clear
s+s = screenshot          s+a = area shot    s+w = window shot
l+l = lock screen
r+s+t = reset             b+o+t = bootloader
```

## LOWER LAYER (left thumb hold)
```
1 2 3 4 5  |  6 7 8 9 0     <- numbers
- = [ ] \  |  _ + { } |     <- symbols (with HRM)
⌃← ⌃⇧⇥ ⌘Z ⌃⇥ ⌃→ | SWAP ⇧⇥ ( )  <- nav + swapper
```

## RAISE LAYER (right thumb hold)
```
F1-F6      |  F7-F12        <- function keys
⌘X ⌘C PgUp ⌘V ⌘+ | ← ↓ ↑ → (HRM)  <- edit + arrows
MOUSE Home PgDn End ⌘- | LEADER 🔇 🔉 🔊 ⏯  <- nav + media
```

## MOUSE LAYER (auto-exit on any other key)
```
Left hand = WASD movement + scroll
Right hand = click buttons (L/M/R)
Modifiers available for Cmd+click etc.
```
