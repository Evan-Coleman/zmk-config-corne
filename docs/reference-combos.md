## SYMBOLS (Vertical: Top + Home Row)
```
  Q ── ! ── A        W ── @ ── S        E ── # ── D        R ── $ ── F
  │         │        │         │        │         │        │         │
  1───────►13        2───────►14        3───────►15        4───────►16

  T ── % ── G        Y ── ^ ── H        U ── & ── J        I ── * ── K
  │         │        │         │        │         │        │         │
  5───────►17        6───────►18        7───────►19        8───────►20

  ; ── ? ── P
  │         │
 10───────►22
```

**Memory trick:** These follow the number row! Q=1=!, W=2=@, E=3=#, etc.

## BRACKETS (Horizontal: Adjacent Keys)
```
PARENTHESES ( )          SQUARE [ ]              ANGLE < >
   E ─── R                  D ─── F                R ─── T
   3     4                 15    16                4     5
     (                       [                       <

   U ─── I                  J ─── K                Y ─── U
   7     8                 19    20                6     7
     )                       ]                       >

CURLY { }
   C ─── V                  , ─── .
  27    28                 32    33
     {                       }
```

**Memory trick:** Opening brackets on left hand, closing on right. Rows go: () top, [] home, {} bottom.
